A personal relationship management app to help you maintain meaningful connections with your friends. Track contact history, set goals, and stay on top of your social relationships.

## 🚀 Features

### Core Features

1. **🔝 Navbar**
   - Responsive navbar with logo on the left
   - Navigation links: Home, Timeline, Stats with icons
   - Active page highlighting

2. **🎯 Banner Section**
   - Centered title and subtitle on Home page
   - "Add a Friend" button with icon
   - 4 summary cards displaying key metrics

3. **📋 Friend Data Management**
   - JSON-based friend profiles with realistic data
   - Each profile includes: id, name, picture, email, days_since_contact, status, tags, bio, goal, next_due_date
   - Status types: "overdue", "almost due", "on-track"

4. **👫 Friends Grid**
   - 4-column responsive grid layout
   - Friend cards showing picture, name, days since contact, tags, and status-based coloring
   - Click to navigate to friend details

5. **👤 Friend Details Page**
   - Two-column layout
   - Left: Friend info card with picture, name, status, tags, bio, email, and action buttons (Snooze, Archive, Delete)
   - Right: Stats cards, Relationship Goal card, Quick Check-In card

6. **⚡ Quick Check-In Functionality**
   - Call, Text, Video buttons that log interactions
   - Automatic timeline entry creation
   - Toast notifications on interaction

7. **📜 Timeline Page**
   - Chronological display of all interactions
   - Icons for different interaction types (Call/Text/Video)
   - Date and title for each entry

8. **🦶 Footer**
   - Matches design specifications
   - Social links and copyright information

9. **📱 Responsive Design**
   - Fully responsive across mobile, tablet, and desktop
   - Optimized layouts for all screen sizes

10. **🛠️ Additional Requirements**
    - 404 page for invalid routes
    - Loading animation during data fetch
    - Toast notifications for interactions
    - Proper deployment with no reload errors


## 🛠️ Technologies Used

- **Frontend Framework:** React.js 18.3.1
- **Build Tool:** Vite 8.0.8
- **Styling:** Tailwind CSS 3.4.0 + DaisyUI
- **Routing:** React Router DOM 6.23.1
- **Charts:** Recharts 2.12.0
- **Icons:** Lucide React, React Icons
- **Deployment:** Vercel
- **Version Control:** Git & GitHub
